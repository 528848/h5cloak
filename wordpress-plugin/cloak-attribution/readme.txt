斗篷系统 v2 的 WordPress / WooCommerce 接入插件。同一地址：带有效归因参数的访客看到真实页面，其余访客看到审核内容。

== Description ==

* 服务端接入：每个前台请求调用斗篷网关 `POST /api/open/v2/decision`（HMAC-SHA256 签名），由网关判定真实 / 审核。
* 地址不变（推荐）：审核页与真实页都可在当前 URL 以 200 输出，可选平台模板（仅审核）、站内页面、本地 HTML 文件、外部地址内容，或深度代理整站（回源审核站并把其域名改写成本站域名，点击不跳走，流量留在本服务器）。
* 真实页默认「继续显示当前网站」：带归因参数的访客直接看到他打开的页面，无需另建真实页。
* 兼容 V1 的跳转：审核页与真实页均可选 302 跳转到站内页面、外部链接（https 白名单）或 HTML 文件地址，覆盖旧版 cloak-api 的全部输出方式（地址会变）。
* 访客令牌：按接口返回写入 Cookie，回访无参数也能识别。
* WooCommerce：可对全部商店页面或仅指定商品 / 分类（含对应购物车、结账）判定。
* 跨浏览器交接：在微信 / 抖音等内置浏览器中放行时，页脚注入「在浏览器中打开」引导条（需在站点开启交接）。
* 排除规则、跳过已登录用户、网关不可用时的降级策略、回访判定本地缓存、连接测试。
* 从旧版 cloak-api 插件自动迁移配置（密钥需换成 `sk_` 服务端密钥）。

== Installation ==

1. 上传 `cloak-attribution` 目录到 `wp-content/plugins/`，启用插件。
2. 商户后台 → 站点 → 密钥，复制 `sk_` 开头的服务端密钥。
3. WordPress 后台 → 设置 → Cloak 归因，填写网关地址与密钥，点击「测试连接」。
4. 选择审核内容输出方式，勾选「启用」，保存。

建议在 `wp-config.php` 中定义密钥而不是保存到数据库：

`define('CLOAK_API_BASE', 'https://entry.example.com');`
`define('CLOAK_SECRET', 'sk_xxxxxxxxxxxx...');`

== Frequently Asked Questions ==

= 与旧版 cloak-api 插件能否同时启用？ =
不建议。启用本插件后请停用旧版插件，配置会在本插件激活时自动迁移。

= 为什么测试连接提示「密钥前缀不存在」？ =
v2 使用站点的服务端密钥（`sk_` 开头），不是旧版的 `ck_` Key。若站点是旧版本创建的，需要在后台重置一次密钥。

= 使用了页面缓存插件怎么办？ =
判定按访客区分，整页缓存会让所有人看到同一结果。请对站点关闭整页缓存，或把需要判定的路径排除出缓存。

== Changelog ==

= 2.3.8 =
* 引导弹框只出现在已放行的真实页。默认浏览 10 秒后弹出，可关闭，并按冷却和次数再试。电脑和手机文案分开。

= 2.3.7 =
* 应用内浏览器的引导弹框改由客户站点上的 JS SDK 绘制，点击后交给系统默认浏览器。插件只传入要打开的地址。

= 2.3.6 =
* 深度代理缓存按天设置，保存时换算成秒。0 天关闭，最长 30 天。

= 2.3.5 =
* 深度代理结果按页面缓存在本机。同一页面在有效期内直接返回，不再回源审核站。
* 设置页可改缓存秒数，并提供「清除深度代理缓存」。

= 2.3.4 =
* 只按当前选中的输出方式取地址。未选中的「拉取外部地址」不再参与，避免把访客 301 到其它网站。
* 选中「使用平台配置的审核模板」时，跟随后台审核源站按当前路径回源。
* 深度代理地址改为普通文本框，可保存不带协议的主机名；源站跳到其它域名时不再把 Location 交给浏览器。

= 2.3.3 =
* 审核源是整站根地址时，当前路径（页面、样式、脚本、图片、字体）按地址回源，并沿用源站的 Content-Type。不再把首页 HTML 套到 CSS 地址上。
* 深度代理时，本站磁盘上不存在的静态文件直接回源审核站。

= 2.3.2 =
* 深度代理的样式、脚本、图片和字体不再交给本站（本站没有审核站主题文件，会 404，页面只剩裸链接）。看过审核页的访客，这些资源改从审核站回源。

= 2.3.1 =
* 深度代理改写补全：审核页里的链接、跳转地址、标题和正文域名都会换成当前站点域名。压缩响应会先解压再替换；「拉取外部地址」和接口回退输出也走同一套改写。

= 2.3.0 =
* 内置服务端 SDK 的深度代理：审核内容可选「深度代理整站」，在本机回源审核站并把审核站域名改写成本站域名后原地输出，地址栏不变、站内链接不跳走。

= 2.2.2 =
* 设置页更清晰：审核 / 真实内容的输出方式分成「A 同域输出（地址不变）」和「B 兼容 V1 的跳转（地址会变）」两组；每个选项下加说明；明确「使用平台配置的审核模板」对应斗篷商户后台的审核内容，并提示「服务端拉取外部地址」等本地模式会覆盖平台模板。

= 2.2.1 =
* 兼容整页缓存：被判定的请求会定义 DONOTCACHEPAGE 等常量并发送不缓存指令，阻止 W3 Total Cache、WP Super Cache、LiteSpeed、WP Rocket 把某个访客的内容缓存后发给所有人。启用后请先清空一次缓存插件。

= 2.2.0 =
* 健壮性：前台判定、页脚引导条、插件加载全部包裹异常兜底，任何错误都降级为审核内容或静默跳过，绝不触发 WordPress 关键错误。
* 兼容性：对 wp_doing_autosave 等较新函数做存在性检查；支持 WordPress 5.6+ 与 PHP 7.4–8.3，标注 Tested up to 6.8。
* 发送响应头前统一检查 headers_sent，主题提前输出时不再报 warning。
* 写访客 Cookie 时跳过空域名并捕获异常，避免 PHP 8 的 setcookie ValueError。
* 服务端拉取外部地址内容限制响应体积并只缓存较小页面，防止整页内容撑爆数据库。
