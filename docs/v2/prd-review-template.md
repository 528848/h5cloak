## 2. 要解决的问题

斗篷在无归因时返回审核内容，地址栏不变。现在平台模板只能贴一段 HTML。商户若想用一整站当审核页，只能每个站点单独填审核源站，或每个站点单独上传压缩包。平台侧不能把「一个网址」或「一整套静态站」做成可复用模板。

本模块把平台模板收成三种来源，站点选用后网关按类型出审核内容：

| 来源 | 商户看到的审核页 | 适合 |
| --- | --- | --- |
| 网址 | 网关把访客的路径和参数原样回源到这个网址 | 已经做好的审核站 |
| HTML | 所有路径都返回这一份渲染后的 HTML | 单页说明、合规占位 |
| 静态项目 | 按路径当静态文件服务器出文件 | 宝塔式上传的整站，含页面、图片、脚本、样式 |

站点自己的审核源站、站点自己上传的静态包继续可用，本模块不删它们。

## 3. 现状

| 能力 | 现在 |
| --- | --- |
| 平台模板 | 编码、名称、说明、一段 HTML。总后台用弹窗编辑 |
| 站点审核来源 | 审核源站 / 平台模板 / 站点静态包，三选一 |
| HTML 模板 | 用 `{{.siteName}}`、`{{.slogan}}` 填变量；任意路径都返回同一份 HTML |
| 站点静态包 | 压缩包解压到站点目录，缺文件时回入口页（单页应用回退） |
| 生效 | 保存后重建站点快照，网关数秒内按快照出内容 |

## 4. 角色

| 角色 | 能做的事 |
| --- | --- |
| 超级管理员 | 新建、编辑、上传、回滚、删除模板 |
| 运营管理员 | 查看列表和详情，不能改 |
| 商户 | 在站点里选用模板。HTML 模板可填本站变量。不能改平台模板正文 |

权限沿用 `system:template:list`、`system:template:edit`。

## 5. 模板本身

每条模板有：名称、编码、说明、来源类型、状态（启用 / 停用）、更新时间。编码在平台内唯一，创建后不可改。停用后，已选用它的站点在快照更新后改为内置占位页，并在站点审核配置上显示「模板已停用」。

三种来源不能混在一条模板里。改来源类型时，旧内容保留到保存成功，避免选错类型把内容清掉。已有站点引用时，改来源要先确认。

### 5.1 网址

- 必填完整 `http` 或 `https` 地址，作为审核站根地址。
- 访客请求 `https://商户域名/products/1?x=1` 且判定为审核时，网关请求 `{根地址}/products/1?x=1`。
- 可填回源 Host。不填则使用网址里的主机名。
- 超时 1–30 秒，默认 8 秒。
- 保存时探测根地址。失败仍允许保存，状态记为异常，列表用危险色标出。
- 不允许指向本机、内网、云元数据地址。

### 5.2 HTML

- 正文为 HTML 文本，最大 1MB。
- 继续支持 `{{.siteName}}`、`{{.slogan}}`。商户在站点里填这两个变量。
- 语法错误不能保存，提示出错位置。
- 判定为审核时，不论访客路径，都返回渲染后的这一份 HTML。
- 响应带 `X-Robots-Tag: noindex`。

### 5.3 静态项目

按静态文件服务器处理，不执行 PHP 或其他服务端脚本。

- 上传一个 `.zip`。解压后的站点根里要有入口文件，默认 `index.html`，可改成别的相对路径。
- 压缩包上限 50MB，解压后文件数不超过 2000，单文件不超过 20MB。超出拒绝并说明原因。
- 拒绝目录穿越、符号链接、绝对路径。`.php`、可执行文件只按静态文件下载或按扩展名返回，不运行。
- 访问规则：
  - 目录请求补入口文件，例如 `/` 和 `/about/` 找该目录下的入口文件。
  - 文件存在则按扩展名返回，支持 Range。
  - 文件不存在返回 404。
  - 「单页应用回退」默认关闭。打开后，找不到的路径改返回入口文件。这是给前端路由用的，不是默认行为。
- 每次成功上传生成一个新版本。保留最近 5 个版本，可回滚。回滚后已选用的站点在快照更新后使用该版本。
- 详情里展示文件树的前两层、入口文件、当前版本、包大小。

## 6. 站点怎么用

站点审核来源仍是三选一：审核源站、平台模板、本站点静态包。

选平台模板时：

- 只列出启用的模板，并显示来源类型。
- HTML 模板额外填站点名和口号，提供预览。
- 网址和静态项目不能改平台上的内容，只能选用。页面说明「内容由平台模板提供」。
- 保存后数秒内网关按模板类型出审核内容。真实内容的回源不受影响。

服务端接入和 JS SDK：HTML 模板继续在判定结果里带渲染后的 HTML。网址模板带根地址和「请按路径回源」的提示，不把整站抓进响应。静态项目由托管网关自己出文件；服务端接入只被告知类型是静态项目，不把压缩包内容塞进判定响应。

## 7. 页面

总后台遵循 `docs/前端UI规范.md`。列表页用概览卡片、搜索卡片、表格卡片。编辑用独立表单页，不用现在这种窄弹窗。

### 7.1 列表

概览四张卡：全部、HTML、网址、静态项目。数字可点，点击即按该类型筛选。

搜索：关键字（名称或编码）、来源类型、状态。回车搜索，重置即清空并搜索。

表格列：编码、名称、来源、状态、被引用站点数、更新时间、操作。操作是文字按钮：编辑、预览、删除。静态项目多一个「版本」。删除前确认。有站点引用时不允许删除，提示先解除引用。停用也要确认。

### 7.2 新建和编辑

独立表单页：

- 顶部说明这块模板会在无归因时作为审核内容。
- 第一张卡是基本信息：编码、名称、说明、来源、状态。
- 第二张卡随来源变化：网址卡、HTML 卡或上传与版本卡。
- 底部操作栏右对齐：取消回到列表，保存带加载状态。
- 来源切换若会丢弃未保存内容，先确认。

HTML 卡的多行输入说明可使用的变量。网址卡在地址下方用一行次要文字说明回源方式。上传使用拖拽上传，只接受 `.zip`，展示进度和失败原因。

### 7.3 预览

- HTML：用示例变量渲染，抽屉里看结果。
- 网址：只显示探测结果（状态码、最终地址、耗时），不在总后台里嵌套打开对方网站。
- 静态项目：新窗口打开平台提供的预览入口，只读当前版本的文件。预览入口不挂到商户正式域名上。

## 8. 验收

1. 新建 HTML 模板并被站点选用后，无归因访问任意路径都返回渲染后的 HTML，带分销码的访问仍是真实内容。
2. 新建网址模板指向一台测试审核站。无归因访问 `/products/1` 返回该站 `/products/1` 的内容，地址栏仍是商户域名。
3. 上传含 `index.html`、`about.html`、`assets/app.js` 的压缩包。无归因访问这三个路径分别得到对应文件；访问不存在的路径得到 404。打开单页应用回退后，不存在的路径改为入口文件。
4. 上传第二版并回滚，站点在数秒内回到上一版。
5. 停用模板后，选用它的站点改为占位页。有引用时删除被拒绝。
6. 运营管理员能看不能改。内网地址和过大的压缩包被拒绝并有明确原因。
7. 原有「审核源站」和「站点静态包」的站点行为不变。

## 9. 不在本阶段

- 在线上改静态项目里的单个文件。
- 执行 PHP、Node 或任何上传进来的服务端程序。
- 用对象存储替换本机目录。多节点部署仍沿用现有限制：文件在网关本机目录。
- 商户自建模板库。商户继续用站点审核源站或站点静态包。
