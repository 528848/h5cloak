# 下载中心 PRD

## 1. 文档信息

| 项 | 内容 |
| --- | --- |
| 模块 | 商户端「下载中心」 |
| 文档版本 | v1 |
| 上游 | `docs/v2/prd-v2.md` 报表导出、`docs/前端UI规范.md` |
| 配套 | `docs/v2/technical-design-download-center.md` |
| 本阶段 | 只定产品和方案，不改代码 |

## 2. 要解决的问题

报表导出已经是异步的：点「导出当前报表」后，任务进队列，worker 生成 CSV，24 小时内凭签名链接下载。现在这些任务挤在「报表」页的「导出记录」页签里。顶栏的下载图标没有独立页面，生成中的任务只能靠人记住去翻页签。

下载中心把所有异步导出收成一个列表页。报表页只负责发起导出，不再承担下载。

## 3. 现状

| 项 | 现在 |
| --- | --- |
| 发起 | 报表各页签的「导出当前报表」调用 `POST /merchant/export` |
| 类型 | 决策日志、渠道、分销码、活动码、路径、转化 |
| 状态 | 排队中、生成中、已完成、失败 |
| 下载 | 完成后签发 24 小时签名链接，`GET /api/export/download/:token` |
| 完成通知 | 站内通知和 `export.done` Webhook，链接指向报表页的导出页签 |
| 界面 | 报表内嵌表格，只有刷新、状态和下载 |
| 分销码列表导出 | 仍是浏览器当场下载，不进这个队列 |

## 4. 角色

商户端登录用户。查看列表和下载沿用 `report:view`。发起导出沿用 `report:export`。只读账号能下载别人已生成的本商户文件，不能新建导出。只能看到本商户的任务。

## 5. 发起导出

报表页保留「导出当前报表」。点击后：

1. 按当前站点、时间范围和页签创建任务。
2. 提示「已加入下载中心」。
3. 不跳进报表里的导出页签。提示里给一个「去下载中心」的入口。

决策日志如果之后增加导出，也创建同一类任务，不另做一套下载列表。分销码列表的当场导出本阶段不动。

同一商户同时排队或生成中的任务最多 3 个。超出时拒绝，并说明去下载中心等待。

## 6. 下载中心页面

独立页面「下载中心」，路径 `/merchant/download`。不出现在侧边栏。顶栏下载图标进入这一页。图标在有「排队中」或「生成中」任务时显示数字，没有进行中的任务时不显示数字。

页面按列表页规范：概览卡片、搜索卡片、表格卡片。

### 6.1 概览

四张卡，点击即按该状态筛选：

| 卡 | 含义 |
| --- | --- |
| 进行中 | 排队中 + 生成中 |
| 可下载 | 已完成且未过期 |
| 已过期 | 已完成但超过 24 小时 |
| 失败 | 生成失败 |

### 6.2 搜索

类型、状态、创建时间。回车搜索，重置即清空并重新搜索。类型用现有六种导出名称。状态下拉含排队中、生成中、可下载、已过期、失败。

### 6.3 表格

列：任务编号、类型、范围、状态、行数、大小、创建时间、过期时间、操作。

范围用一句话写清，例如「近 7 日 · 全部站点」或「今日 · 站点名称」。不直接展示站点数字 ID。

状态标签：排队中 info，生成中 primary，可下载 success，已过期 info，失败 danger。失败时在标签旁显示错误原因。

操作：

- 可下载：下载。
- 失败：重试。重试生成一条新任务，不覆盖失败记录。
- 排队中：取消。取消前确认。
- 生成中：没有取消，避免文件写到一半。
- 已过期：没有下载。说明文件已清理。

列表在存在进行中任务时每 5 秒刷新一次。全部结束后停止刷新。

空状态说明：在报表里导出后，文件会出现在这里。

## 7. 文件生命周期

- 生成成功后 24 小时内可下载。过期后接口拒绝，页面状态变为已过期。
- 过期文件由现有清理任务删除。页面不提供手动删除。
- 单次导出最多 20 万行，与现在一致。超出时任务失败，原因写明已达到行数上限。
- 下载仍走签名链接。链接过期或被改过返回 410 或 403，页面提示重新打开下载中心。

## 8. 通知

导出完成后，站内通知和 Webhook 保持。通知里的链接改为 `/merchant/download`，不再打开报表页签。

## 9. 验收

1. 在报表点导出后，出现「已加入下载中心」，报表不再切到导出页签。
2. 顶栏下载图标进入下载中心。有进行中任务时图标带数字，任务完成后数字消失。
3. 排队中的任务在数秒内变为生成中，再变为可下载。下载得到的 CSV 能用 Excel 打开中文。
4. 失败任务可以重试，列表多出一条新任务。排队中的任务可以取消。生成中的任务没有取消。
5. 超过 24 小时的任务显示已过期，下载按钮不可用。
6. 只读账号能看和下载，不能从报表发起导出。其他商户的任务不可见。
7. 报表页不再有「导出记录」页签。

## 10. 不在本阶段

- 分销码列表的当场导出改为异步。
- 总后台下载中心。
- 把导出文件改存到对象存储。
- 邮件发送导出文件。
