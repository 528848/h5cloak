## 2. 要解决的问题

现在 Telegram 是「平台一个 Bot，商户只填 Chat ID」：

- 所有商户共用一个机器人，消息都从同一个账号发出，无法用自己的品牌机器人。
- 配置靠人工抄 Chat ID，群的负数 ID 难懂、易填错。
- 只能平台单向推告警，不能主动问数据，也没有每日日报。

本期三件事：

1. **每个商户配置自己的机器人。** 后台可视化填 Bot Token，校验通过后，告警 / 日报 / 问答都从该商户自己的机器人发出。
2. **自然语言问答。** 在绑定会话里用中文问「今天多少访问」「有没有告警」等，机器人只读返回该商户数据。
3. **每日定时日报。** 设定整点时间，每天主动发昨日概况。

配置方式：用绑定深链 / `/bind` 自动抓会话，**不再手抄 Chat ID**。

## 3. 现状 → 目标

| 项 | 现在 | 目标 |
| --- | --- | --- |
| Bot | 平台一个，Token 在 `worker.env` | 每商户一个，Token 加密存库；平台 Bot 作兜底 |
| 商户配置 | 只填 `telegram_chat_id` | Token + 一键绑定会话 + 日报开关 |
| 方向 | 只出不进 | 出站告警/日报 + 入站问答 |
| 入站 | 无 | worker 内 getUpdates 长轮询（无需公网 webhook） |
| 问答 / 日报 | 无 | 规则意图识别 + 每日整点日报 |

## 4. 角色与权限

- 查看：`alert:view`；修改：`alert:edit`。
- 只读账号能看机器人与绑定状态，不能改 Token、不能解绑、不能改日报。
- 机器人只按「会话绑定的商户」回数据，绝不跨商户。
- 同一 Telegram Bot 只能被一个商户占用；冲突时拒绝保存并提示。

## 5. 页面与配置

### 5.1 入口

| 页面 | 路径 | 作用 |
| --- | --- | --- |
| 通知设置 | `/merchant/alert/settings` | 渠道开关；引导「配置我的机器人」；保留老的 Chat ID 兜底 |
| 机器人配置 | `/merchant/alert/telegram-setup` | Token、绑定会话、日报、测试 |
| 教程 | `/merchant/alert/telegram` | 创建 Bot → 填 Token → 绑定 → 问答说明 |

### 5.2 机器人 Token

1. 商户用 `@BotFather` 建机器人，拿到 Token（`123456789:AA...`）。
2. 配置页粘贴 Token → 保存。系统 `getMe` 校验：
   - 成功：显示 `@用户名`、状态「已连接」、Token 尾号 4 位；worker ≤30s 内开始长轮询。
   - 失败：提示「Token 无效或无法连接 Telegram」，不保存。
   - 已被其他商户占用：提示「该机器人已被其他商户使用」。
3. Token 加密存库，页面不回显明文。可「更换 Token」或「移除机器人」（会话记录保留）。

### 5.3 绑定接收会话

- **绑给自己：** 「生成绑定方式」→ 「在 Telegram 中打开并绑定」深链 `t.me/<bot>?start=<码>` → 点开始即绑定。页面轮询到列表出现后提示成功。
- **绑到群：** 拉机器人进群 → 发一次性指令 `/bind <码>`。
- 绑定码：一次性、**10 分钟**过期。
- 一个商户最多 **10** 个启用会话；超出需先解绑。告警与日报发给所有**启用**会话。
- 每条会话可单独停用 / 解绑。

### 5.4 日报

- 开关；发送时间：每天整点（0–23，默认 09:00），按商户时区（缺省 `Asia/Shanghai`）。
- 范围：首期固定**全部站点汇总**（不做站点下拉，避免配置复杂）。
- 内容见 §7；当天同一时间只发一次；会话里发「日报」可立即补发。

### 5.5 渠道与测试

- 「启用的通知渠道」勾选 Telegram 后，告警才走 Telegram。
- 「发送测试」：有自有 Bot 且已绑定 → 向所有启用会话发；否则走平台 Bot + Chat ID。

## 6. 自然语言问答

### 6.1 首期问法

| 商户说 | 机器人回 |
| --- | --- |
| 今天多少访问 / 今天访问量 | 今日访问、真实、审核、首访/回访 |
| 昨天转化多少 | 昨日转化数与金额 |
| 这周怎么样 / 近 7 天 | 近 7 日访问与转化概况 |
| 有没有告警 / 最近告警 | 未恢复告警（类型、站点、时间） |
| 日报 / 来份日报 | 立即补发昨日日报 |
| 帮助 / help / 菜单 | 问法清单 |

- 命令：`/today` `/yesterday` `/7d` `/alerts` `/report` `/help`；绑定用 `/start <码>` `/bind <码>`。
- 多站点可带站点名：「今天 站点A 多少访问」；不写则汇总全部。
- 听不懂 → 友好提示 + 问法清单。

### 6.2 边界

- **只读统计**，不改配置、不导出、不给密钥。
- 未绑定会话：只回绑定指引。
- 单会话每分钟最多 **20** 条回复，超出提示稍后再问。

### 6.3 智能程度

首期关键词 + 规则即可。**LLM 兜底不在本期**（见 §10）。

## 7. 日报与告警内容

### 7.1 日报

标题：`📊 {商户名} 昨日日报 {日期}`，含：访问/真实/审核/拦截、首访/回访/交接、转化与金额、Top 渠道与分销码各前 3、未恢复告警数、看板链接。

### 7.2 告警

沿用现有告警事件。有自有 Bot → 从自有 Bot 发到所有启用会话；否则平台 Bot + Chat ID。消息体不变。

## 8. 验收

1. 粘贴合法 Token → 显示 `@用户名` + 已连接；非法 Token 报错且不保存；已被占用的 Bot 拒绝。
2. 点深链 → Telegram 点开始 → 后台数秒内出现绑定会话；全程不抄 Chat ID。
3. 群内 `/bind <码>` 绑定成功，群能收到测试消息。
4. 「今天多少访问」「有没有告警」「帮助」回复正确；未绑定会话拿不到数据。
5. 开启日报 09:00，次日 09:00 收到；`/report` 可立即补发。
6. 源站不可达告警从自有 Bot 发出。
7. 商户 A 的机器人绝不返回商户 B 的数据。
8. 只读账号不能改 Token / 解绑 / 改日报。
9. 未配自有 Bot 时，老的平台 Bot + Chat ID 仍可用。

## 9. 兼容与迁移

- 保留平台 Bot 与 `notify_settings.telegram_chat_id`。
- 配了自有 Bot 并完成绑定后，告警优先走自有 Bot；老 Chat ID 字段可留作未配自有 Bot 时的兜底。
- **不自动把老 Chat ID 迁入绑定列表**（缺类型与会话名，且无法验证仍有效）。引导商户用绑定深链重新绑一次。
- 不强制迁移，不删老字段。

## 10. 不在本阶段

- 机器人内写操作（改源站、导出、建码）。
- 富交互（按钮菜单、图表图）。
- 日报按单站点筛选 UI。
- LLM 意图兜底、多语言。
- 总后台统一管理各商户机器人。
- 公网 webhook 入站（本期用长轮询，见技术方案）。
