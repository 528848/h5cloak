## 1. 文档信息

| 项 | 内容 |
| --- | --- |
| 模块 | 商户端「斗篷列表」 |
| 文档版本 | v1 |

## 2. 要解决的问题

商户端现在同时有「站点管理」和「斗篷列表」，点进去是同一批站点。站点是 V2 的反向代理：域名、源站、审核模板、归因参数。V1 的斗篷是另一件事：访客打开一条短链，系统按模式和访问条件决定 302 到真实链接还是审核链接。

斗篷列表要回到 V1 那条产品，不再复用站点列表。站点管理保持不动。

## 3. 和站点管理的边界

| | 站点管理 | 斗篷列表 |
| --- | --- | --- |
| 访客看到的地址 | 绑定域名上的路径保持不变，网关回源 | 先打开斗篷短链，再跳到真实链接或审核链接 |
| 放行依据 | 点击参数、分销码、回访 | 模式、地区、来源、设备、PC、代理、语言 |
| 真实内容 | 真实源站 | 一条或多条真实链接里的第一条 |
| 审核内容 | 审核源站、平台模板或站点静态包 | 审核链接；选本地模版时见第 6 节 |
| 一条记录 | 一个站点 | 一条斗篷 |

一条域名不能同时给托管站点和斗篷用。托管站点继续走反向代理。斗篷域名只负责短链跳转。

## 4. 现状

| 项 | 现在 |
| --- | --- |

| V1 表单里未接到入口的项 | 本地模版、快速审核标签、中间页只保存和展示，入口不使用 |

## 5. 角色

| 角色 | 能做的事 |
| --- | --- |
| 商户管理员、商户操作员 | 查看、新建、编辑、复制、启停 |
| 商户管理员 | 另外可以删除 |
| 商户只读 | 只查看列表和链接 |

新权限：`cloak:cloak:list`、`cloak:cloak:add`、`cloak:cloak:edit`、`cloak:cloak:status`、`cloak:cloak:copy`、`cloak:cloak:remove`。不再用站点权限控制这个页面。

## 6. 一条斗篷

必填：名称、关联域名、至少一条真实链接、审核链接（审核页模式为跳转外链时）、模式、状态。

| 字段 | 规则 |
| --- | --- |
| 名称 | 1–64 字，本商户内可重复 |
| 关联域名 | 本商户已校验通过、且没有被站点占用的域名。创建后不可改 |
| 真实链接 | 一条或多条 `http`/`https`。放行时用第一条。每条最长 1000 字 |
| 审核页模式 | `跳转外链` 或 `本地模版` |
| 审核链接 | 跳转外链时必填。本地模版时可以空 |
| 快速审核 | Google、Facebook、TikTok、通用安全页。只在本地模版时显示，用来选内置文案 |
| 跳转短链 | 系统生成或自定义。系统生成形如 `https://{域名}/c/{6位}`。自定义必须是 `https://{该域名}/c/{编码}`，编码 4–32 位字母数字。全平台唯一 |
| 允许访问来源 | facebook、google、tiktok、kwai、不限制。含「不限制」时忽略其他项。默认不限制 |
| 模式 | 斗篷、绿色、全开、审核。见第 7 节 |
| 投放地区 | 国家或地区代码，可空。空表示不限地区 |
| 蜘蛛白名单 | Googlebot、Bingbot、Facebook External Hit、TikTok Bot，可多选。命中的爬虫去审核链接 |
| 设备白名单 | 不选表示不限。可选仅移动端、仅平板、仅 PC、移动端+平板 |
| 访问限制 | 屏蔽空语言、屏蔽 PC、屏蔽代理。打开后该类访问去审核链接 |
| 中间页 | 不使用、系统模版、自定义模版。见第 8 节 |
| 状态 | 启用、停用。新建默认启用 |
| 备注 | 最多 200 字 |

中国及港澳台不作为投放地区。表单顶部保留说明：斗篷仅适用于海外市场。

复制：新的一条，名称加「副本」，短链重新生成，其余字段相同，状态为停用。

删除：二次确认。删除后短链立即 404，访问记录保留到商户日志保留期。

停用：短链返回 404，不跳转。启用前若同域名短链编码冲突，拒绝启用。

## 7. 访问时怎么判定

只处理 `https://{斗篷域名}/c/{编码}`。其它路径不进斗篷，避免抢走站点。

顺序固定：

1. 域名不是启用斗篷的域名，或编码对不上：404。
2. 斗篷停用、商户停用或到期：404。
3. 模式是绿色或审核：去审核侧。
4. 模式是全开：去真实链接。
5. 模式是斗篷时，下面任一成立就去审核侧，否则去真实链接：
   - 打开了屏蔽 PC，且设备是 PC
   - 打开了屏蔽代理，且请求像代理（存在 `Via`，或 `X-Forwarded-For` 里有多个地址）
   - 打开了屏蔽空语言，且没有 `Accept-Language`
   - 填了投放地区，且 IP 国家不在其中。没有地区库时，这条不拦截，并在访问记录里记「地区未知」
   - 允许来源不是「不限制」，且 Referer 对不上所选来源
   - 爬虫的 UA 命中蜘蛛白名单
   - 设了设备白名单，且当前设备不在里面

审核侧：跳转外链则 302 到审核链接。本地模版则 200 返回内置审核页，地址栏留在短链，带 `X-Robots-Tag: noindex`。

真实侧：302 到第一条真实链接。

V1 的黑白名单若命中，黑名单去审核侧，白名单去真实侧，并且先于模式。V1 代码里两种名单都进了审核链接。本期名单页不恢复，判定不读名单。名单模块做了之后再接到第 3 步之前。

## 8. 中间页

V1 只在列表上显示中间页选项，入口没有插入中间页。本期把它接到跳转前面：

- 不使用：直接 302 或返回本地审核页。
- 系统模版：先 200 返回一页「继续访问」。访客点击后再到真实链接或审核链接。
- 自定义模版：同一页，正文用商户填的一段文字，最多 500 字。未填则用系统文案。

本地模版的审核结果不再套中间页，避免两页叠在一起。

## 9. 列表

列表页遵循 UI 规范：概览卡片、搜索卡片、表格卡片。

概览：全部斗篷、启用中、已停用、今日跳转次数。点前三张按状态筛选。今日跳转只展示，不筛选。

搜索：名称、关联域名、模式、状态。回车搜索，重置清空并立刻再查。

表格列与 V1 对齐：

| 列 | 内容 |
| --- | --- |
| 名称 | 点进编辑 |
| 链接信息 | 真实链接、审核链接、跳转短链，各自可复制。本地模版没有审核链接时显示「本地模版」 |
| 状态 | 启用 / 停用 |
| 投放地区 | 代码，空为「不限」 |
| 模式 | 斗篷 / 绿色 / 全开 / 审核 |
| 备注 | 空为 `-` |
| 链接数据 | 审核次数、真实次数、今日审核次数、今日真实次数 |
| 创建时间 | |
| 设备白名单 | 空为「不限」 |
| 屏蔽 PC | 是 / 否 |
| 屏蔽代理 | 是 / 否 |
| 允许访问来源 | |
| 中间页 | 不使用 / 系统模版 / 自定义模版 |
| 操作 | 编辑、复制、启停、删除 |

次数按访问记录累计。今日按商户时区的自然日。只计最终去了审核侧或真实侧的访问，404 不计入。

字段多，编辑用独立表单页 `/merchant/cloak/form`，不用窄弹窗。底部固定「取消 / 保存」。

## 10. 不做的事

- 不改站点管理、归因、分销码、网关回源。
- 不把现有站点自动变成斗篷。
- 不恢复 V1 的访问日志页、黑白名单页、API Key 页。
- 不提供总后台斗篷列表。
- 短链不按域名「最新一条启用斗篷」兜底。编码对不上就是 404。

## 11. 验收

1. 侧边栏「站点管理」和「斗篷列表」进入不同页面，数据互不影响。
2. 新建一条斗篷后，列表能看到三条链接和四项次数，次数初始为 0。
3. 斗篷模式、全开、绿色、审核四种模式下，用 PC、手机、指定 Referer、地区内和地区外各访问一次，跳转与第 7 节一致。
4. 停用后短链 404。删除后短链 404，列表不再出现。
5. 复制出的新斗篷短链不同，且默认停用。
6. 只读账号看不到新建、编辑、复制、启停、删除。
7. 已被站点占用的域名不能选为斗篷域名。站点域名上的普通访问仍走反向代理。
